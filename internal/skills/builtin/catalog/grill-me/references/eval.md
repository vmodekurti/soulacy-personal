# Eval — grill-me

1. **"Grill me on my plan to move to Lisbon next year"** → first round asks only frontier questions, numbered, each with a recommended answer phrased so "yes" accepts it.
2. **Frontier of nine questions on a phone** → asks the five that unblock most and says four remain.
3. **A question depends on another in the same round** → deferred to a later round.
4. **Fact available from memory or the web (e.g. visa rules, last trip budget)** → looked up and used in the recommendation; not asked.
5. **"I never fly red-eyes"** → recorded with `person.observe`; later recommendations respect it.
6. **Frontier empty** → summary of every decision; waits for confirmation before handing off or acting.
7. **"Let's stop here"** → summary of what is settled and a list of open decisions; nothing acted on.
