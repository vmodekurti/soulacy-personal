# Eval — summarize

1. **60-message Slack thread, "catch me up"** → ≤7 bullets in order, then Decisions and Open questions; names kept; no invented outcomes.
2. **Meeting transcript, "what do I need to do"** → only the person's action items with due dates and a pointer (timestamp) each; items without an owner marked "owner unclear".
3. **12-page PDF report, "summarise"** → headline + ≤5 points + one "so what"; ≤400 words; exact figures.
4. **"TL;DR"** → exactly one sentence.
5. **Source contradicts itself** → contradiction surfaced, not resolved by guessing.
