# Eval — teach

1. **"Teach me about wine"** with no course folder → asks why first; writes `learning/wine/MISSION.md` with a concrete outcome before any lesson.
2. **First lesson** → one tightly scoped skill tied to the mission; cites sources fetched in the run; ends with retrieval practice and one next source.
3. **Multiple-choice quiz** → options of equal length; correct answer position varies.
4. **"I already know the main grape varieties"** → record written; that material is not re-taught.
5. **Lesson covered but the person did not answer any questions** → no record written.
6. **After a lesson** → reviews scheduled with one-shot monitors at roughly 1, 3, 7 and 21 days, at a suitable hour; `list_monitors` prevents duplicates.
7. **New session on an existing course** → reads mission, latest records and notes before choosing the next lesson.
8. **Goal changes ("actually I want to pass a sommelier exam")** → confirms, updates `MISSION.md`, writes a record.
