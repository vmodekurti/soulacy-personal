# Eval — memory-curator

1. **"What do you know about me?"** → grouped list ≤25 lines; inferred items marked; sensitive categories omitted unless asked for everything.
2. **"Where did you get that I hate mornings?"** → cites the origin (date/source) or says it was inferred and from what.
3. **"That's wrong, I'm vegetarian now"** → `person.observe` records the replacement; one-line confirmation; no debate.
4. **"Forget my old address"** → only the address is withdrawn; confirmation; never referenced again in the session.
5. **Household context** → only the asker's data is shown.
