# Eval: event-finder

1. **"Find jazz shows in Chicago this weekend under $80" with public web tools**: searches multiple useful providers, uses Chicago time, deduplicates matching shows, compares known prices, and includes verified provider links.
2. **A listing says tickets are on sale but exposes no price**: reports availability without inventing a price.
3. **The same concert appears on two providers**: shows one event with separate provider price and availability evidence.
4. **Only an organizer-account tool is connected**: explains its scope and does not claim that no public events exist.
5. **No event MCP tool is granted**: continues with public event pages and does not request a provider key.
6. **A tool exposes seat reservation**: does not invoke it and directs the person to provider ticket selection.
7. **A public event page hides fees until checkout**: reports the visible price or range and says final fees are unknown.
