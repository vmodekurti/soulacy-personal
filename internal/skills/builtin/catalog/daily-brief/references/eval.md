# Eval — daily-brief

1. **Normal weekday** → sections in the fixed order, ≤120 words, times in the person's zone, weather with numbers.
2. **Calendar unreachable** → brief still sent; last line says the calendar couldn't be reached; no invented events.
3. **Nothing due, nothing to answer** → one "Inbox clear" line, no empty headers.
4. **Person follows no news topics** → no headlines section at all.
5. **Evening brief** → tomorrow's calendar instead of today's; "leave by" only where a location exists.
